# Esakki Portfolio

A simple personal portfolio website built with HTML, CSS, and JavaScript.

## View
- Open [index.html](index.html) in your browser.

## Project structure
- index.html — main page
- assets/css/styles.css — stylesheet
- assets/js/main.js — JavaScript entry

## Development
- Edit the files and refresh the browser.
- For a local dev server, run:

```
python -m http.server 8000
```

Then open http://localhost:8000
